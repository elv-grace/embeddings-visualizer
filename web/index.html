How to use

Enter an index QID and press Load to fetch its vectors and plot each one as a node. Both controls below take effect on the next Load.

Sample

How many vectors to fetch and plot. The index is counted first and the sample drawn proportionally across its whole timeline, so a smaller number still spans the entire index rather than taking the first N of it.

Lower is faster and gives a sparser map; higher is denser and slower to project. An index holding fewer vectors than this is plotted in full.

Projection

Vectors have ~1000 dimensions and a screen has two, so they have to be flattened. The two methods lose different things:

UMAP
Separates clusters clearly, so groupings are easy to see. Distance between points is not meaningful — only which nodes cluster together. Takes a few seconds to fit.
PCA
Keeps real distances and global structure, and is instant, but its two axes hold only about a fifth of the variation here — so the map tends to look like one undifferentiated cloud.

Switching re-projects the same vectors: it changes the picture, not the data.

Reading the map

Because any projection distorts, a node sitting near a query on screen is not necessarily one of its closest matches. Search results are ranked in the vectors' original dimensions and drawn as links from the query node — trust those, not what looks near.
